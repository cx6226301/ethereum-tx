字符表（索引 0–35，位移对其取模）：

0123456789abcdefghijklmnopqrstuvwxyz

  1. 输入校验：64 位十六进制，0x 前缀可选（如带则剥离）；统一转小写，仅加密 64 位本体。
  2. 随机位移 k ∈ [1, 35]，每个字符替换为表中 (index + k) mod 36 位置的字符。密文不含位移值。
  3. 随机穿插杂质字符，池为 A-Z 与 !%^*()[]{}:,.<>?~（已避开 # = $ 空格 引号 反斜杠 等 .env / docker-compose 敏感字符）。
  4. 解密：删除所有不在 [0-9a-z] 内的字符 → 得到 64 位串 → 遍历 k = 1..35 反向位移 → 前缀 0x 得候选私钥 → 推导地址与目标地址核对，取唯一命中。
